# Solmaris

Solmaris is an original, sun-soaked coastal open-world crime game set in the city of Solmaris. You play as Jax Moreno, exploring on foot or behind the wheel while traffic and pedestrians bring the streets to life. Take on missions and follow the story, use combat when trouble finds you, and manage a wanted system as police respond to escalating crime.

The game includes a HUD with a north-up minimap, health, money, XP, rank, vehicle speed, weapon, district, objective, and wanted level information. A start screen introduces the controls and story, while save and load options preserve progress. Synthesised sound accompanies the coastal city, and the story unfolds through jobs, dialogue, driving, exploration, and encounters across the streets.

## Run it

From the repository root, start the static server:

```sh
node serve.ts
```

Then open [http://localhost:8080](http://localhost:8080) in a desktop browser.

## Controls

- `WASD` moves Jax and steers vehicles.
- `Shift` runs, `Space` jumps or uses the handbrake, and the mouse looks around.
- `E` enters, steals, exits, and interacts; `F` talks or interacts at story beacons.
- `Q` switches between fists and pistol; left click attacks; `R` reloads.
- `M` mutes sound and `Esc` pauses or releases the mouse.
